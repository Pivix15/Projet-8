# Nina Carducci | Photographe

Site vitrine one-page pour une photographe à Bordeaux, optimisé SEO, performance et accessibilité.

🔗 [Voir le site](https://pivix15.github.io/Projet-8/)

## Stack

HTML5 · CSS3 · Bootstrap · jQuery · MauGallery

## Le site avant intervention

1. Suivez ce lien : [https://nina-carducci.github.io/](https://nina-carducci.github.io/)

## Fonctionnalités

* Présentation du portfolio de Nina Carducci, avec des photos classées par catégorie (mariages, portraits, concerts, entreprises).
* Diaporama de présentation en page d'accueil.
* Portfolio filtrable par tag, avec lightbox pour agrandir chaque photo.
* Présentation des services proposés (shooting, retouches, album photo) avec les tarifs associés.
* Formulaire de contact permettant aux visiteurs de faire une demande de devis ou de collaboration.

## Améliorations apportées

* **SEO** : title et meta description optimisés, structure de titres (Hn) cohérente, attributs alt descriptifs, données structurées Schema.org pour le référencement local, balises Open Graph et Twitter Card pour un partage propre sur les réseaux sociaux.
* **Performances** : compression et redimensionnement des images en WebP, ajout de `fetchpriority` sur l'image du LCP, scripts déplacés en fin de page, fichiers CSS/JS minifiés.
* **Accessibilité** : ajout de balises HTML5 sémantiques, association des labels aux champs du formulaire, correction des contrastes de couleurs insuffisants (audit WAVE).
* **Débogage** : correction des incohérences de structure et des erreurs de code relevées lors des audits Lighthouse et WAVE.

## Lancer en local

Ouvrir `index.html` dans un navigateur (ou Live Server pour un rendu fidèle).
